연경쌤의 업무 도구함

설치 없이 브라우저에서 바로 쓰는 교사 업무 도구 모음입니다.

  • 설치·가입 없음
  • 파일이 컴퓨터 밖으로 나가지 않음
  • 무료 · 광고 없음
  • PDF 업무 도구

    여러 PDF를 합치고 쪽을 정리합니다. 이름·주민등록번호를 가명으로 바꿔 AI에 넣고, 답은 실제 이름으로 되돌립니다.

    • 합치기·쪽 정리
    • 개인정보 가명 처리
    • Markdown 변환
    열기
  • 한글 문서 변환

    공문·계획서(hwpx)를 AI가 읽기 좋은 Markdown으로 바꿉니다. 문단 번호와 표를 살리고 이름은 가명으로 바꿉니다.

    • hwpx → Markdown
    • 표·문단 번호
    • 가명 처리·되돌리기
    열기
  • 사진 도구

    학생 얼굴과 이름표를 가리고, 여러 장의 용량을 한꺼번에 줄입니다. 저장본에는 촬영 위치가 남지 않습니다.

    • 모자이크
    • 용량 줄이기
    • 아이폰 사진(HEIC)
    • 위치 정보 지우기
    열기
  • 동영상 편집기

    긴 촬영 영상에서 필요한 부분만 남기고 자막과 배속을 넣습니다. 자르기만 했다면 화질 그대로 바로 저장됩니다.

    • 자르기·이어 붙이기
    • 자막
    • 배속
    • 용량 줄이기
    열기
  • 움짤 메이커

    웹앱 화면을 녹화해 기능별로 잘라 움직이는 그림(GIF)으로 만듭니다. 블로그에 올릴 용량에 맞춰 줍니다.

    • 화면 녹화
    • GIF·webp
    • 목표 용량 맞춤
    열기
  • QR 코드 만들기

    주소 여러 개를 이름이 붙은 QR로 한 장에 모아 인쇄합니다. 하트 모양 QR로도 만들 수 있고, 만료되지 않습니다.

    • 한 장에 모아 인쇄
    • 하트 모양 QR
    • 읽기 확인
    열기

파일은 내 컴퓨터 안에서만

문서·사진·영상을 서버로 보내지 않습니다. 모든 처리는 지금 열어 둔 브라우저 안에서 끝납니다.

남기지 않습니다

쿠키나 저장소를 쓰지 않습니다. 창을 닫으면 넣은 파일과 작업 내용이 모두 사라집니다.

설치도 가입도 없이

크롬이나 엣지에서 주소만 열면 됩니다. 학교 컴퓨터에 프로그램을 깔 필요가 없습니다.
