# 사진 도구

블로그나 가정통신문에 올릴 사진을 한꺼번에 줄이고, 학생 얼굴이나 이름표를 가리는 도구입니다.

**모든 처리는 브라우저 안에서만 이루어집니다.** 사진을 서버로 보내지 않고 어디에도 저장하지 않습니다. 새로 고치거나 창을 닫으면 모두 사라집니다.

## 기능

- **넣기**: JPG·PNG·WebP·GIF·BMP·AVIF와 아이폰 사진(HEIC·HEIF). 끌어다 놓기, 여러 장 선택, 캡처한 화면 붙여 넣기(`Ctrl+V`).
- **줄이기**: 긴 변 크기(원본·2560·1920·1280·800px), 형식(JPG·PNG 유지·WebP), 화질, 장당 용량 제한(2MB·1MB·500KB·200KB). 설정을 바꾸면 모든 사진을 다시 줄이고 줄어든 용량을 바로 보여 줍니다.
- **가리기**: 사진을 눌러 가릴 곳을 드래그합니다. 모자이크·흐리게·검게 칠하기 중에서 고르고, 옮기거나 크기를 바꾸거나 지울 수 있습니다(`Delete`). 90° 돌리기도 여기서 합니다.
- **위치 정보 지우기**: 저장본에는 촬영 위치·시각·기기 정보가 들어가지 않습니다. 원본에 촬영 위치가 들어 있으면 목록에 "위치 정보 있음"으로 표시합니다.
- **저장**: 낱장 저장 또는 ZIP 하나로 모두 저장.

## 구성

정적 파일만으로 동작합니다. 빌드 과정이 없습니다.

```
index.html           화면과 모든 동작 (목록, 가리기, 줄이기, ZIP 저장)
heic-worker.js       HEIC를 푸는 일꾼(웹 워커). 화면이 멈추지 않게 따로 돕니다
icon.svg             도구 목록 페이지에 나오는 아이콘
lib/libheif-1.23.5/  HEIC 디코더 (약 2MB)
```

- 저장본은 사진을 캔버스에 새로 그려서 만듭니다. 그래서 원본에 들어 있던 정보(EXIF)가 따라오지 않고, 가린 부분 아래의 원래 그림도 남지 않습니다.
- 목록 그림·가리기 화면·저장본이 같은 함수(`paint`)로 그려지므로 보이는 대로 저장됩니다.
- 모자이크는 가린 영역의 짧은 변을 8칸으로 뭉갭니다. 영역 크기에 비례하므로 사진을 줄여도 가려지는 정도가 같습니다.
- 사진은 필요할 때마다 풀고 바로 버립니다(가리기 화면에 띄운 한 장만 들고 있음). 수십 장을 넣어도 메모리가 쌓이지 않습니다.
- HEIC 디코더는 HEIC 사진을 처음 넣을 때 불러옵니다.
- 라이브러리는 저장소에 직접 넣었습니다. CDN을 포함해 바깥으로 나가는 요청이 없고, `index.html`의 Content-Security-Policy가 브라우저 차원에서 막습니다.
- localStorage, IndexedDB, 쿠키를 쓰지 않습니다.

## 실행

저장소 루트에서 정적 서버를 띄우고 `/photo/`를 엽니다. `index.html`을 파일로 직접 열면(`file://`) HEIC 일꾼을 불러오지 못합니다.

```bash
npx serve
```

## 조정값

`index.html` 스크립트 맨 위 `CFG`에 모여 있습니다.

- `QUAL`: 화질(높음·보통·낮음)별 JPG·WebP 품질값(0.9·0.8·0.65).
- `MOSAIC_CELLS`(8), `BLUR_DIV`(5): 모자이크 칸 수와 흐림 세기. 값이 작을수록 더 알아보기 어렵습니다.
- `MIN_QUAL`(0.4): 용량 제한에 맞출 때 화질을 낮추는 한계. 이보다 낮춰야 하면 크기를 줄입니다.

## 한계

- 얼굴을 자동으로 찾아 주지는 않습니다. 가릴 곳은 직접 드래그해야 합니다.
- 흐리게는 영역이 크면 윤곽이 남을 수 있습니다. 확실히 가려야 하면 모자이크나 검게 칠하기를 쓰세요.
- 사진 자르기(크롭), 밝기·색 보정은 없습니다.
- GIF는 첫 장면만 사진으로 저장합니다.
- PNG를 PNG 그대로 저장하면 화질 설정이 적용되지 않아 용량이 크게 줄지 않습니다.
- HEIC의 위치 정보 표시는 파일 구조에 따라 놓칠 수 있습니다(그때는 "확인하지 못했습니다"로 나옵니다). 저장본에서는 어느 쪽이든 지워집니다.
