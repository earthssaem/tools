# 동영상 편집기

수업이나 실험을 찍은 긴 영상에서 필요한 부분만 남기고, 자막과 배속을 넣어 mp4로 저장하는 도구입니다.

**모든 처리는 브라우저 안에서만 이루어집니다.** 영상을 서버로 보내지 않고 어디에도 저장하지 않습니다. 새로 고치거나 창을 닫으면 편집 내용이 사라집니다. 데스크톱 크롬·엣지 기준입니다.

## 기능

- **자르기·이어 붙이기**: 재생 위치에서 나누기(`S`), 앞·뒤 지우기(`Q`·`W`), 조각 삭제(`Delete`), 조각 끝을 끌어 다듬기, 순서 바꾸기. 영상을 여러 개 넣으면 순서대로 이어 붙입니다.
- **자막**: 재생 위치에 추가(`T`)하고, 타임라인에서 끌어 옮기거나 길이를 바꿉니다. 화면 위 위치는 미리보기에서 끌어 정합니다. 자막은 원본 영상의 장면에 붙어 있어서, 앞부분을 잘라 내거나 조각 순서를 바꿔도 같은 장면에 남습니다.
- **화면**: 필요한 부분만 남기는 자르기(비율 고정 가능), 90° 돌리기. 영상 파일 단위로 적용됩니다.
- **속도·소리**: 조각마다 0.5~8배속(음높이는 그대로), 음량 0~300%, 소리 끄기. 배경음악(mp3·m4a·wav) 넣기, 반복, 끝에서 서서히 줄이기.
- **되돌리기**: `Ctrl+Z` / `Ctrl+Y`.

## 저장 방식 두 가지

| | 빠른 저장 | 새로 만들기 |
| --- | --- | --- |
| 방식 | 원본 데이터를 그대로 옮겨 담음(다시 인코딩 안 함) | 프레임을 풀어서 다시 인코딩 |
| 속도 | 수십 분짜리도 몇 초 | PC의 인코더 성능에 따름 |
| 화질 | 원본 그대로 | 화면 크기·화질·목표 용량을 고름 |
| 쓸 수 있는 편집 | 자르기, 이어 붙이기, 순서 바꾸기, 원래 소리 모두 끄기 | 전부 |

- 빠른 저장은 조각이 키프레임에서 시작해야 해서, 조각의 시작이 표시한 자리보다 조금 앞당겨질 수 있습니다. 얼마나 당겨지는지는 내보내기 창에 나옵니다.
- 형식(코덱·크기·소리 형식)이 서로 다른 영상을 섞었으면 빠른 저장을 쓸 수 없습니다.
- 크롬·엣지에서는 저장할 파일을 먼저 고르고 거기에 바로 써 나가므로, 긴 영상도 메모리에 쌓이지 않습니다.

## 구성

정적 파일만으로 동작합니다. 빌드 과정이 없습니다.

```
index.html               화면과 모든 동작 (미리보기, 타임라인, 소리 처리, 내보내기)
icon.svg                 도구 목록 페이지에 나오는 아이콘
lib/mediabunny-1.66.3/   영상 파일을 읽고 쓰는 라이브러리 (약 0.8MB)
```

- 영상을 풀고 다시 만드는 일은 브라우저에 들어 있는 인코더·디코더(WebCodecs)가 합니다. 그래픽 카드의 하드웨어 가속을 쓰기 때문에 ffmpeg.wasm보다 훨씬 빠릅니다.
- 미리보기와 내보내기가 같은 함수(`compose`)로 한 장면을 그리므로, 보이는 대로 저장됩니다.
- 새로 만들 때 화면과 소리를 나란히 만들면서 한쪽이 1.5초 넘게 앞서가지 않게 붙잡습니다. 그래서 영상 길이와 상관없이 메모리를 조금만 씁니다.
- 배속을 건 조각의 소리는 WSOLA 방식으로 음높이를 유지한 채 빠르기만 바꿉니다.
- 라이브러리는 저장소에 직접 넣었습니다. CDN을 포함해 바깥으로 나가는 요청이 없고, `index.html`의 Content-Security-Policy가 브라우저 차원에서 막습니다.
- localStorage, IndexedDB, 쿠키를 쓰지 않습니다.

## 실행

저장소 루트에서 정적 서버를 띄우고 `/video/`를 엽니다. `index.html`을 파일로 직접 열면(`file://`) 모듈을 불러오지 못해 동작하지 않습니다.

```bash
npx serve
```

## 조정값

`index.html` 스크립트 맨 위 `CFG`에 모여 있습니다.

- `BPP`: 화질(높음·보통·낮음)별 픽셀당 비트 수. 1080p 30fps에서 약 8·5·3Mbps입니다.
- `MAX_FPS`(30): 새로 만들 때의 프레임 수 상한.
- `GATE_SEC`(1.5): 화면과 소리가 서로 앞서갈 수 있는 한도.

## 한계

- 브라우저가 재생하지 못하는 형식(예: 일부 PC의 H.265, AVI, WMV)은 불러올 수 없습니다.
- 장면 전환 효과, 영상 겹치기(화면 속 화면), 그림 넣기, 조각별 화면 자르기는 지원하지 않습니다.
- 결과물의 화면 비율은 첫 조각을 따릅니다. 비율이 다른 조각은 검은 띠가 생깁니다.
- 자막 하나는 한 영상 파일 안에서만 이어집니다.
- 8배속처럼 빠른 구간의 소리는 알아듣기 어렵습니다. 그런 조각은 소리를 끄는 편이 낫습니다.
- AAC 인코더가 없는 환경(리눅스 크롬 등)에서는 소리를 Opus로 저장합니다.
