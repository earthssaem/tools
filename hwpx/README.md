# 한글 문서 변환

한글 문서(.hwpx)를 AI에 넣기 좋은 Markdown으로 바꾸는 도구입니다. 문단 번호와 표를 살리고, 이름을 가명으로 바꿨다가 AI의 답에서 다시 실제 이름으로 되돌릴 수 있습니다.

**모든 처리는 브라우저 안에서만 이루어집니다.** 문서를 서버로 보내지 않고 어디에도 저장하지 않습니다. 새로 고치거나 창을 닫으면 문서와 대응표가 모두 사라집니다.

## 기능

- **변환**: 문단, 문단 번호(1. 가. 1) 가) …), 글머리표, 표(합친 칸 포함), 글상자, 각주·미주, 수식, 하이퍼링크를 Markdown으로 옮깁니다. 여러 문서를 한꺼번에 넣을 수 있습니다.
- **미리보기 / Markdown**: 문서처럼 보는 화면과 Markdown 원문을 오가며 확인합니다.
- **개인정보**: 이름(학생·교사·학교), 주민등록번호, 휴대전화, 이메일, 학번, 주소를 `[학생A]` 같은 이름표로 바꿉니다. 바뀐 곳은 미리보기에 노란 표시로 나옵니다. 이름표는 [PDF 업무 도구](../pdf/)와 같은 방식입니다.
- **되돌리기**: AI가 이름표로 쓴 글을 붙여 넣으면 실제 이름으로 바꾸고 조사(은/는, 이/가 …)도 맞춥니다.
- **내보내기**: 복사, `.md` 저장, 여러 문서 이어서 복사, ZIP으로 모두 저장.

## 옛 형식(.hwp)은

읽지 못합니다. 한글에서 **파일 → 다른 이름으로 저장하기**를 눌러 파일 형식을 **한글 표준 문서(\*.hwpx)**로 바꿔 저장한 뒤 넣어 주세요.

## 바꾸는 규칙

- **문단 번호**: 한글이 화면에만 그려 주는 자동 번호(문서 안에는 글자로 들어 있지 않음)를 번호 모양 정의에서 다시 만들어 붙입니다.
- **표**
  - 한 칸짜리 표는 글상자처럼 쓴 것이므로 인용문(`>`)으로 옮깁니다.
  - 간격을 벌리려고 둔 빈 줄·빈 칸과 쓰이지 않는 칸 나눔은 걷어 냅니다.
  - 합친 칸이나 표 속의 표가 있으면 HTML 표(`<table>`)로, 없으면 Markdown 표로 씁니다. "표" 설정에서 한쪽으로 고정할 수 있습니다.
- **제목**: 본문에서 가장 많이 쓰인 글자 크기를 기준으로, 그보다 1.5배 이상 큰 짧은 줄은 `#`, 1.2배 이상은 `##`, 조금 크고 굵으면 `###`로 봅니다. 추정이므로 끌 수 있습니다.
- **그림·개체**: 내용은 옮기지 못하고 `[그림]`, `[개체]`로 자리만 표시합니다. 캡션이 있으면 `[그림: 캡션]`.
- **수식**: 한글 수식 스크립트를 `[수식: …]`으로 옮깁니다.
- **머리말·꼬리말, 메모**: 기본으로는 빼고, 고르면 넣습니다. 숨은 설명과 누름틀 안내문은 넣지 않습니다.

## 구성

정적 파일만으로 동작합니다. 빌드 과정도, 외부 라이브러리도 없습니다.

```
index.html      화면과 모든 동작 (hwpx 읽기, Markdown 변환, 가명 처리, 되돌리기)
icon.svg        도구 목록 페이지에 나오는 아이콘
```

- hwpx는 XML 파일을 ZIP으로 묶은 형식입니다. ZIP은 직접 읽고, 압축은 브라우저에 들어 있는 `DecompressionStream`으로 풉니다.
- 문서를 "문단·표·글상자" 덩어리로 읽어 둔 뒤, 가명 처리는 그 덩어리의 글에 하고, 미리보기와 Markdown은 같은 덩어리에서 만듭니다.
- `index.html`의 Content-Security-Policy가 같은 주소 밖으로 나가는 요청을 브라우저 차원에서 막습니다.
- localStorage, IndexedDB, 쿠키를 쓰지 않습니다.

## 실행

저장소 루트에서 정적 서버를 띄우고 `/hwpx/`를 엽니다.

```bash
npx serve
```

## 한계

- 변환은 글과 구조만 옮깁니다. 글자색, 정렬, 굵게·밑줄 같은 꾸밈은 옮기지 않습니다.
- 그림 속 글자, 차트, OLE 개체의 내용은 읽지 못합니다.
- 가명 처리는 적어 준 이름과 정해진 꼴(주민등록번호·전화번호 등)만 찾습니다. 별명, 오타, 그림 속 이름은 찾지 못하므로 내보내기 전에 미리보기를 훑어봐야 합니다.
- 학교 이름은 "○○초등학교·중학교·고등학교" 꼴과 그 줄임말만 자동으로 찾습니다. 교사 이름은 직접 적어야 합니다.
- 암호가 걸린 문서는 열 수 없습니다.
- 변경 내용 추적으로 지운 글이 문서에 남아 있으면 그 글도 함께 나옵니다.

## 검증

공개된 hwpx 예제 1,348개(한글이 저장한 문서, 정부 서식 포함)를 변환해 오류가 없는지, 문서의 글 조각이 결과에 빠짐없이 들어가는지 확인했습니다. 문단 번호는 [hwpxlib](https://github.com/neolord0/hwpxlib)의 번호 예제와 같은 결과가 나오는지 맞춰 보았습니다.
