# PDF 업무 도구

개인 업무용 PDF 도구입니다. PDF를 합치고 정리한 뒤, 개인정보를 가명으로 바꿔 PDF 또는 AI 입력용 Markdown으로 내보냅니다.

**모든 처리는 브라우저 안에서만 이루어집니다.** 파일, 추출한 글자, 가명 대응표를 서버로 보내지 않고 어디에도 저장하지 않습니다. 새로 고치거나 창을 닫으면 모두 사라집니다.

## 기능

- **편집**: 여러 PDF의 페이지를 한 화면에 펼쳐 놓고 순서 바꾸기(끌어서 옮기기), 파일 이름순(ㄱㄴㄷ) 정렬과 파일 단위 이동, 삭제, 90° 회전, 실행 취소/다시 실행, 전체 저장·선택 저장
- **개인정보**: 이름(직접 입력), 주민등록번호, 휴대전화, 이메일, 학번을 찾아 글자 데이터 자체를 지우고 그 자리에 `[학생A]` 같은 이름표를 넣습니다. 적용한 뒤에는 글자를 다시 추출해 원래 문자열이 남았는지 검증하고, 남아 있으면 저장과 복사를 막습니다.
- **Markdown**: 가명 처리한 문서에서 제목·문단·목록·표를 살려 Markdown으로 바꿉니다.
- **되돌리기**: AI가 이름표로 쓴 글을 붙여 넣으면 실제 이름으로 바꿉니다.

## 구성

정적 파일만으로 동작합니다. 빌드 과정이 없습니다.

```
index.html      화면과 모든 동작 (MuPDF 작업용 워커 코드 포함)
lib/pdfjs/      pdf.js — 썸네일·크게 보기 렌더링
lib/pdf-lib/    pdf-lib — 합치기, 삭제, 순서, 회전, 저장
lib/mupdf/      MuPDF.js(WASM) — 글자·좌표 추출, 글자 데이터 삭제, 부속 정보 제거
```

- 라이브러리는 저장소에 직접 넣었습니다. CDN을 포함해 바깥으로 나가는 요청이 없습니다.
- `index.html`의 Content-Security-Policy가 같은 주소 밖으로 나가는 요청을 브라우저 차원에서 막습니다.
- MuPDF(약 10MB)는 개인정보·Markdown 탭을 처음 열 때 불러옵니다.
- localStorage, IndexedDB, 쿠키를 쓰지 않습니다. 방문 분석·오류 수집 스크립트도 없습니다.

## 실행

GitHub에 올리고 Vercel에 정적 사이트로 배포하면 됩니다(설정 없음).

내 컴퓨터에서 볼 때는 이 폴더에서 정적 서버를 띄웁니다. `index.html`을 파일로 직접 열면(`file://`) 브라우저가 모듈과 WASM을 막으므로 동작하지 않습니다.

```bash
python -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 엽니다.

## 한계

- 스캔본, 사진, 서명처럼 글자 데이터가 없는 부분은 자동으로 찾지 못합니다. 크게 보기에서 마우스로 영역을 직접 그려 지웁니다.
- OCR, PDF 안의 글자 수정, 이미지(JPG/PNG)를 PDF로 바꿔 합치기는 지원하지 않습니다.
- 암호가 걸린 PDF는 열 수 없습니다.
- Markdown의 제목·표·문단은 글자 크기와 좌표로 추정한 결과입니다. 내보내기 전에 미리보기에서 확인하세요.

### 라이브러리 버전을 올릴 때

MuPDF.js는 일부러 1.28.1에 맞춰 두었습니다. 1.28.6에는 문장 중간의 글자를 지우면 뒤따르는 글자가 한 글자 폭만큼 왼쪽으로 밀리는 문제가 있습니다(LibreOffice가 만든 PDF에서 확인). 버전을 올린 뒤에는 가명 처리한 PDF를 크게 보기로 열어 이름표 뒤 글자가 제자리에 있는지, 적용 후 "검증 통과"가 나오는지 확인하세요.
